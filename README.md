# Browser Lock website
Static site for GitHub Pages (no build step).
1. Create a GitHub repo and upload everything in this folder (keep `.nojekyll`).
2. Repo Settings > Pages > Deploy from a branch > `main` / root > Save.
3. Open the link GitHub gives you. To ship a new extension version, replace `downloads/Browser-Lock.zip` (zip must contain the folder `Browser-Lock/` with `manifest.json` inside).
